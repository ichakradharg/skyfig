# Changelog

All notable consumer-facing changes to Skyfig are recorded here. Skyfig follows [Semantic Versioning](VERSIONING.md); generated token names, types, and meanings are public API.

## Unreleased

### Added

- Semantic action, focus, and status color tokens.
- Dynamic Type-aware typography helper for SwiftUI consumers.
- Token accessibility guardrails and consumer guidance.

### Changed

- The warning status token now meets the checked contrast target on supported light surfaces.

## Release-note template

For each tagged release, replace the Unreleased section with a version and date, then state:

- changed token families and their intended visual impact;
- whether the release is patch, minor, or major and why;
- required consumer migration steps, if any; and
- screens that should receive visual review after the package update.
