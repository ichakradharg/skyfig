# Skyfig showcase

`SkyfigShowcase` is a small macOS SwiftUI executable that consumes the committed generated tokens exactly as an application would.

```bash
swift run SkyfigShowcase
```

Toggle the system appearance to see the same typed color tokens resolve for light and dark themes.
# Examples

- [Skyfig consumer sample](SkyfigConsumer/README.md) is a standalone iOS 26+ SwiftUI app that imports Skyfig through a separate package boundary.
- [Skyfig package consumer](SkyfigPackageConsumer/README.md) is a minimal package-level smoke test for the public API.
