# Consumer screenshot baselines

This directory stores the committed light-mode iPhone and iPad baseline images for the consumer sample:

- `iphone-light.png` — compact iPhone layout.
- `ipad-light.png` — adaptive iPad layout.

Use the [consumer visual-regression guide](../../../Docs/VISUAL_REGRESSION.md) for dedicated-Mac runner setup, exact recording and verification commands, baseline-review criteria, and the current light-only scope. Never commit Xcode `xcuserdata`, derived data, or temporary actual screenshots here.
