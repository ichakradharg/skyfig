# Troubleshooting token updates

Use the [repository troubleshooting guide](https://github.com/ichakradharg/skyfig/blob/main/Docs/TROUBLESHOOTING.md) for fixture validation, generated-source freshness, live Figma synchronization, and consumer-app update failures.

Skyfig consumers do not need Figma credentials. The central publisher repository owns Figma access and produces reviewed package versions; an app consumes those versions through ``SkyfigTokens``.
