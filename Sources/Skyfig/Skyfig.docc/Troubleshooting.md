# Troubleshooting token updates

Use the repository’s `Docs/TROUBLESHOOTING.md` guide for fixture validation, generated-source freshness, live Figma synchronization, and consumer-app update failures. In a team-owned fork, use the copy in that fork rather than upstream guidance.

Skyfig consumers do not need Figma credentials. The publisher repository owns Figma access and produces reviewed package versions; an app consumes those versions through ``SkyfigTokens`` or the configured team namespace in a fork.
